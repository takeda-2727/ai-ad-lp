# AI生成広告サービス LP

広告のすべてをAIで生成する新規事業のトップページ。今はデザインの原型で、HTML1枚だけのシンプルな構成にしている。

## 構成

- `index.html` … トップページ本体（CSSも中に入っている）

## 見かた

`index.html` をブラウザで開けばそのまま見られる。

## まだ埋めていないところ

ページ内の `[ ]` で囲んだ部分はプレースホルダー。決まったら差し替える。

- [サービス名] / [運営者名] / [年]
- 料金プラン：[料金] / [枚数] / [本数]
- 動画の [秒数]
- デモの [店舗名] と [コピー案A〜C]
- FAQの回答（AIツールの商用利用規約、写真・ロゴの扱い、再生成の条件）
- お問い合わせ・LINEボタンのリンク先

## メモ

- アクセントカラーはライム `#C6F432`。変えるときはファイル内を一括置換する。
- 光るグロー（`rgba(198,244,50,…)`）も同じ色なので、色を変えるならこっちも合わせる。
