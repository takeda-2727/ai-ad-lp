# AIコマーシャル+ LP

AIを使って広告動画を制作する新規事業のトップページ。売りは従来の広告制作より安いことと、公開までが速いこと。今はデザインの原型で、ビルドなしの素の HTML で書いている。

## 構成

項目ごとにページを分けている。構成と部品の形は https://gakusite.jp/ を参考にしている。メニューはパソコンではヘッダーに並べ、1080px 以下でハンバーガー（全画面）になる。

- `index.html` … トップ（ヒーロー・対応媒体と数字・サービス・強み・デモ・私たちについて・FAQと料金）。初回だけオープニングが出る
- `about.html` … 私たちについて（チームの紹介・YouTube・概要）
- `flow.html` … しくみ
- `service.html` … サービス
- `strengths.html` … 強み（安くて速い理由）
- `price.html` … 料金
- `faq.html` … よくある質問
- `assets/site.css` / `assets/site.js` … 全ページ共通のスタイルと動き
- `assets/hero.mp4` … ヒーローの動画（任意）。置くとヒーローの背景で自動再生される。無ければ仮のビジュアルが出る
- `assets/service-video.mp4` / `service-banner.mp4` / `service-plan.mp4` / `service-export.mp4` … サービスのカードの動画（任意）。置くと、それぞれ「動画広告」「画像・バナー広告」「企画・コピー提案」「媒体ごとの書き出し」のイラストの代わりに流れる（書き出しはサービスのページだけ）。16:9 で表示する

ヘッダー・メニュー・相談の帯（CTA）・フッターは各ページに同じものを書いている。どれかを変えるときは全ページそろえる。

## 見かた

`index.html` をブラウザで開けばそのまま見られる。

## まだ埋めていないところ

ページ内の `[ ]` で囲んだ部分はプレースホルダー。決まったら差し替える。

- [運営者名] / [年]
- デモの [店舗名] と [コピー案A〜C]
- FAQの回答（AIツールの商用利用規約、写真・ロゴの扱い、再生成の条件）
- お問い合わせ・LINEボタンのリンク先
- YouTube の [チャンネル名]・チャンネルの URL（いまは `href="#"`）・[チャンネルで発信している内容]
- 私たちについての [チームの写真]

## メモ

- アクセントカラーはライム `#C6F432`。`assets/site.css` の先頭の色の変数（`--lime` など）で変える。
- 光るグロー（`rgba(198,244,50,…)`）も同じ色なので、色を変えるならこっちも合わせる。
- アニメーションは `assets/site.css` と `assets/site.js` にまとまっている。端末で「視差効果を減らす」を設定している人には動きを出さない。
